04 · Motion contract

Softly expressed, always purposeful.

The circle motif is progressive feedback, not ambient decoration. Only the element affected by the decision moves. Reduced Motion retains every state change through immediate layout and short opacity transitions.

01 · SELECT

Quiet commitment

Border, fill, and check settle over 160–180 ms with one light haptic. No bouncing cards.

02 · MOVE

Directional continuity

Forward/back steps travel only 12 px over 220 ms. Native stacks still own route transitions.

03 · FORM

One mark at a time

Each completed answer adds one ring, node, or relationship path over 240–320 ms.

04 · COMPLETE

One success, once

The seal settles over 420–520 ms after the server confirms. No confetti or money animation.

Recommended implementation: shared React Native flow + native sheet/date controlsDesign artifact only · no production UI changed
