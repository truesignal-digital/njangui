01

Motion language

  • Press feedback: scale to 0.98 over 100 ms.
  • Waiting/disclosure: enter 180 ms, exit 90 ms.
  • Native stack owns route transitions.
  • Reduced Motion removes scale/slide and keeps a short opacity change.
  • Only one or two elements animate in any state change.
02

Icon contract

  • Heroicons outline for all app-owned icons.
  • Sizes: 16 compact, 20 default, 24 emphasis; stroke visually normalized.
  • No emoji icons and no second custom glyph library.
  • Only OS-owned controls—native tabs, picker arrows, system dialogs—use SF Symbols or Material Symbols.
03

Platform contract

  • types.ts defines one public API.
  • index.ios.tsx hosts SwiftUI; index.android.tsx hosts Compose.
  • Shared React Native content handles cards, lists, data, copy, and accessibility.
  • Platform forks are reserved for controls whose interaction truly differs.
