Dark

Theme changes apply immediately and respect system accessibility settings.

Brand boundary

The Njangi mark is brand artwork. Heroicons still own every functional action, status, and navigation symbol.

Theme behavior

System is default. Light and Dark are local overrides. A 120–180 ms color crossfade is enough; screen geometry does not animate.

Logo motion

No spinning or looping. The handover seal may resolve once in 320–420 ms; Reduce Motion uses a static color change.

Meaning

The arcs represent a continuing circle of people. They never visualize money, a group balance, or custody by Njangi.
